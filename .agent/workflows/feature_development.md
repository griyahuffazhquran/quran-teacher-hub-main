# ⚙️ Workflow: Feature Development

Alur kerja standar untuk pengembangan fitur baru:

1. **Analisis Requirement**: Pahami kebutuhan pengguna dan periksa file komponen terkait di `src/`.
2. **Pencatatan State**: Update `AGENT_STATE.md` bagian _Task Tracker_ dengan task baru.
3. **Pengembangan**:
   - Buat/edit komponen di `src/components/` atau route di `src/routes/`.
   - Gunakan Radix UI & Tailwind CSS.
4. **Verifikasi**:
   - Pastikan dev server berjalan tanpa error console.
   - Tes fungsionalitas dan keterbacaan TypeScript.
5. **Finalisasi**: Update `AGENT_STATE.md` menandai task selesai.
