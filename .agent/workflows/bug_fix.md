# 🐛 Workflow: Bug Fix

Alur kerja perbaikan masalah / bug:

1. **Investigasi Error Log**: Baca error traceback dan log dengan cermat sebelum mengubah kode.
2. **Reproduksi**: Identifikasi baris kode yang menyebabkan bug.
3. **Perbaikan Tepat**: Perbaiki akar masalah tanpa membuat mock/workaround buatan.
4. **Verifikasi**: Jalankan linter dan test build untuk memastikan bug teratasi secara tuntas.
5. **Update State**: Catat ringkasan perbaikan pada `AGENT_STATE.md`.
